# Library API

REST API для управления библиотекой, разработанный на Python с использованием FastAPI и PostgreSQL.

Проект позволяет получать информацию о книгах, проверять их доступность и оформлять выдачу книг читателям.

## Технологии

- **Python** — основной язык программирования.
- **FastAPI** — разработка REST API.
- **PostgreSQL 16** — реляционная база данных.
- **Psycopg2** — подключение Python к PostgreSQL.
- **SQLAlchemy** — ORM-библиотека.
- **Docker** — контейнеризация PostgreSQL.
- **Docker Compose** — управление контейнерами.
- **Pydantic** — проверка входящих данных.
- **Uvicorn** — ASGI-сервер для запуска приложения.

## Функциональность

### 1. Работа с книгами

- Получение списка всех книг.
- Получение информации о конкретной книге по ID.
- Проверка доступности книги.

### 2. Выдача книг

- Выдача книги читателю.
- Проверка существования книги.
- Проверка доступности перед выдачей.
- Сохранение информации о выдаче в PostgreSQL.
- Автоматическое изменение статуса доступности книги.
- Защита от повторной выдачи одной книги с помощью транзакций и уникального индекса PostgreSQL.

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/books` | Получить все книги |
| GET | `/books/{book_id}` | Получить книгу по ID |
| POST | `/loans` | Выдать книгу читателю |

## База данных

Используются две основные таблицы:

**books**

Хранит информацию о книгах:

- `id` — уникальный идентификатор.
- `title` — название книги.
- `available` — доступность книги.

**loans**

Хранит информацию о выдаче книг:

- `id` — идентификатор операции.
- `book_id` — идентификатор книги.
- `reader_id` — идентификатор читателя.
- `loaned_at` — дата и время выдачи.
- `returned_at` — дата и время возврата.

Для предотвращения одновременной выдачи одной книги используется PostgreSQL Partial Unique Index.

## Запуск проекта

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd library-api
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск PostgreSQL через Docker

```bash
docker compose up -d
```

Проверка контейнера:

```bash
docker compose ps
```

### 5. Запуск FastAPI

```bash
uvicorn app.main:app --reload
```

## Пример запроса

**POST /loans**

```json
{
  "book_id": 1,
  "reader_id": 101
}
```

Пример успешного ответа:

```json
{
  "message": "Book successfully loaned",
  "loan_id": 1,
  "book_id": 1,
  "reader_id": 101
}
```

## Обработка ошибок

API использует HTTP-статусы для обработки различных ситуаций:

| Status Code | Description |
|---|---|
| 201 | Запись о выдаче успешно создана |
| 404 | Книга не найдена |
| 409 | Книга недоступна или уже имеет активную выдачу |
| 422 | Ошибка валидации входящих данных |
